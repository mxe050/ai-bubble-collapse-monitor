# AIバブル崩壊・日経平均底値モニター

AI相場の崩壊を検知するだけでなく、**米国AI・半導体相場のストレスが日本へ波及したか**、さらに**日経平均の底値候補にどこまで近づき、反転を確認できたか**を追う日本語ダッシュボードです。

公開ページ: https://mxe050.github.io/ai-bubble-collapse-monitor/

## このページが分けて答えること

1. 米国AI・半導体相場は調整か、利益・投資・信用まで悪化した崩壊か
2. 米国側のストレスが日本株へ短期または持続的に波及したか
3. 日経平均の底値候補はどこか
4. その価格帯に近づき、底打ちの証拠が出たか
5. 下落後もFCFと事業基盤が残る会社はどこか

## SOXと日本株を分ける

SOXはNasdaqの定義上、米国市場に上場する半導体30社の指数です。所在地の制限はなくADRも含みますが、日本株指数ではありません。

本モニターではSOXを米国AI設備投資サイクルの先行価格指標に使い、米国側の崩壊確認と日本への波及を分けます。

- 米国側: SOX、海外AI10社の価格と最新四半期業績、ハイパースケーラーCapEx、供給、米国HY OAS
- 日本側: 日経平均、日本AI・半導体連動8社
- 短期波及: 米国ストレスと日本株の5日下落が重なる
- 持続的波及: 日経平均と日本8社で深い下落、200日線割れ、下落の広がりが複数確認される

米国で下落すれば日本も必ず下落する、とは仮定しません。国際ポートフォリオ、受注・設備投資、日経平均の構成集中、為替・信用を伝播経路として示し、日本側の実データで確認します。

## ITバブル崩壊時の「IT以外への波及」

2000年3月10日のNASDAQ高値から2002年10月9日のNASDAQ安値までを固定窓にし、12系列を同じ条件で比較します。株式分割と配当を調整したYahoo Financeの調整後終値を使い、次の3つを分けます。

- 同じ期間の騰落率: 2000年3月10日から2002年10月9日まで保有した場合の変化
- 期間内最大下落: その窓の中で、各銘柄自身の高値から後の安値まで何%下がったか
- 日本の延長下落: 日本市場は米国の底後も下げたため、2003年4月28日まで最大下落を再確認

期間内最大下落の中央値は、IT・半導体直撃群が約86.1%、市場全体が約54.1%、技術感応型の複合企業が約57.4%、非IT4社が約40.5%でした。個別ではトヨタが約51.1%、ソニーが約73.3%下落しました。ソニーは2000年当時も電子、ゲーム、半導体、情報技術を持っていたため非ITには分類しません。ホンダは期間末では+25.5%でも、途中では最大約37.8%下落しました。

この比較は、非IT企業なら無傷だったという意味ではなく、直撃群より下落が小さい傾向があっても大きな含み損を経験し得ることを示します。ただし、米国景気後退、同時多発テロ、日本のデフレ・銀行不安、イラク情勢が重なった時期であり、IT崩壊だけの因果効果ではありません。存続企業を選んだ小標本なので、生存者バイアスもあります。

## 崩壊スコア

Method v3.5では、崩壊が起きた証拠と、割高への脆弱性を分離しました。

- 崩壊確認80点: 米国価格30、基礎収益・顧客投資25、資本循環・供給15、米国信用10
- 評価への脆弱性20点: 基準FCFシナリオ外の部分と暗黙成長率
- 崩壊確認: 価格、利益、供給・信用の3ゲートがすべて充足し、崩壊確認45/80点以上

評価への脆弱性20点は崩壊確認へ加算しません。DCF残差は余剰現金、保有資産、金融子会社、会計差、循環、一時要因、モデル誤差を含み、バブルの確定額ではありません。

## 業績データの規則

売上、FCF、CapExの変化は、最新四半期と前年同期の同じ四半期を日付で対応させます。TTM系列の隣接値は観測間隔が一定でないため、前年比計算には使いません。

- 比較日が320～410日離れていない場合は未確認
- 売上・FCFは海外AI10社中7社未満しか取れない場合、自動判定に使わない
- CapExは負値の会計表現に依存しないよう投資額の絶対値で比較
- 欠損は0ではなく未確認

## 日経平均の底値モデル

3つの独立した価格アンカーを計算し、最小値から最大値を底値ゾーンとして残します。

- 利益アンカー: `参照日EPS × (1 - 利益悪化率) × ストレス後PER`
- 純資産アンカー: `参照日BPS × ストレス後PBR`
- 歴史アンカー: `直近3年高値 × (1 - 想定下落率)`

EPSとBPSは、日経公式の同じ日の終値と指数ベースPER・PBRから逆算します。2026年7月17日の公式値は終値64,141.12円、PER 22.99倍、PBR 2.71倍です。標準シナリオは利益25%減、PER 16倍、PBR 1.5倍、高値から50%下落ですが、これは予測値ではなく変更可能なストレス前提です。

底値ゾーンへの到達だけでは底打ちとしません。120日安値の更新停止、安値からの反発、50日線、米国HY OAS、日本AI・半導体連動8社の200日線割れを別の確認スコアにしています。8社は本サイト独自の代理指標で、日経225全銘柄の公式市場幅ではありません。

## 企業価値の比較対象

- 海外・AI関連10社: NVIDIA、Broadcom、AMD、Micron、Arm、Marvell、Microsoft、Alphabet、Amazon、Meta
- 日本・AI連動8社: アドバンテスト、東京エレクトロン、ソフトバンクグループ、富士通、キーエンス、日立、信越化学、HOYA
- 日本・分散型8社: ホンダ、キヤノン、トヨタ、ファーストリテイリング、ソニー、任天堂、リクルート、ダイキン

日本株は円、海外株はドルで表示します。金額は直接比べず、評価用FCF利回り、暗黙成長率、時価総額に占めるシナリオ価値を比較します。

トヨタとホンダは金融サービスを含む連結TTM FCFを直接使わず、公式の非金融事業キャッシュフローをFY2022～FY2026の5年中央値に平準化します。金融事業価値は別加算していません。ソフトバンクグループはNAV/SOTP、複合企業は事業別SOTP、半導体装置会社は循環平準化FCFが本来必要です。

## データ更新と自動監査

GitHub Actionsが6時間ごと、およびPages公開前に `scripts/update_data.py` を実行します。

- Yahoo Finance公開チャート: 日経平均、SOX、NASDAQ、各社株価
- Yahoo Finance調整後終値: 2000～2003年のIT直撃群、市場全体、技術感応型・非IT日本企業の固定比較
- Yahoo Finance標準化財務時系列: 売上、FCF、設備投資など
- FRED: 米国ハイイールドOAS
- 日経公式日次サマリー: 指数ベースPER・PBRの固定参照値
- 企業公式IR: トヨタとホンダの非金融事業FCF

`scripts/validate_data.py` が、スキーマ、26社の構成、前年比の日付差、データカバレッジ、米国・日本バスケット、EV・FCF利回り・下落率の計算恒等式、全社DCF前提、トヨタ・ホンダの公式補正と基準DCF比率、日経公式参照値、過去局面、ITバブル比較12系列の騰落率・最大下落率・群中央値・分類、画面要素の対応を検証します。さらに `scripts/smoke_ui.js` が最新データを使って主要な画面計算を最後まで実行します。失敗時は公開しません。

詳しい修正点と残る限界は [FACT_CHECK.md](FACT_CHECK.md) を参照してください。

本サイトは教育・調査用のストレステストです。投資助言、目標株価、売買指示、底値保証ではありません。利益予想、PER/PBR、資本コスト、政策、為替、信用危機、技術競争によって結果は大きく変わります。
