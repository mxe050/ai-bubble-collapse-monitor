# AIバブル崩壊・日経平均底値モニター

AI相場の崩壊を検知するだけでなく、**米国AI・半導体相場のストレスが日本へ波及したか**、さらに**日経平均の底値候補にどこまで近づき、反転を確認できたか**を追う日本語ダッシュボードです。

公開状態: GitHubリポジトリは非公開、GitHub Pagesは停止中です。現在はローカルサーバーで確認します。

## このページが分けて答えること

1. 米国AI・半導体相場は調整か、利益・投資・信用まで悪化した崩壊か
2. 米国側のストレスが日本株へ短期または持続的に波及したか
3. 1900年以降の下落局面と2026年の共通点・相違点は何か
4. 日経平均の底値候補はどこか
5. その価格帯に近づき、底打ちの証拠が出たか
6. AI一極集中からNon-AIへの揺り戻しが始まったか
7. 下落後もFCFと事業基盤が残る会社はどこか

## SOXと日本株を分ける

SOXはNasdaqの定義上、米国市場に上場する半導体30社の指数です。所在地の制限はなくADRも含みますが、日本株指数ではありません。

本モニターではSOXを米国AI設備投資サイクルの先行価格指標に使い、米国側の崩壊確認と日本への波及を分けます。

- 米国側: SOX、海外AI10社の価格と最新四半期業績、ハイパースケーラーCapEx、供給、米国HY OAS
- 日本側: 日経平均、日本AI・半導体連動8社
- 短期波及: 米国ストレスと日本株の5日下落が重なる
- 持続的波及: 日経平均と日本8社で深い下落、200日線割れ、下落の広がりが複数確認される

米国で下落すれば日本も必ず下落する、とは仮定しません。国際ポートフォリオ、受注・設備投資、日経平均の構成集中、為替・信用を伝播経路として示し、日本側の実データで確認します。

## 榊原式の揺り戻し監視

ユーザー提供の榊原先生「市況展望」（2026年7月18日執筆）の考察を、別の日にも同じ方法で再現できるようにした研究用の代理モデルです。

1. 前提: 最新NT倍率が15.5倍以上、または直近252取引日の最高が16倍以上
2. NT倍率の反転: 直近252取引日の最高から5%以上低下し、20日変化もマイナス
3. TOPIXの相対優位: TOPIXが日経平均を5日で1ポイント以上、または20日で2ポイント以上上回る
4. 分散型株の相対優位: 日本・分散型8社の中央値が日本・AI連動8社を5日で2ポイント以上、または20日で4ポイント以上上回る
5. 広がり: 分散型8社の75%以上が日経平均を上回る、または日経平均下落時にも半数以上が上昇

2～5の何項目が同時に成立したかを表示します。相対騰落は「AI株からNon-AI株への資金移動と整合する値動き」を示しますが、売買主体や資金の移動元・移動先を直接証明するものではありません。

日経平均は価格加重、TOPIXは浮動株調整時価総額加重です。原文の「日経平均は時価総額加重」という説明は公式定義に合わせて補正しました。AI連動8社と分散型8社も本サイト独自の固定監視群であり、榊原先生の正式な投資対象銘柄ではありません。各群8社では1社が12.5ポイントを占め、中央値は4番目と5番目の値に左右されます。無作為抽出ではなく、現存しデータ取得できる代表企業を選ぶため、生存者・選択バイアスが入り得ます。統計的有意性は検定していません。

適正値は、原文の2026年7月17日入力を再現しつつ画面上で変更できます。

- 利益アンカー: `EPS × 目標PER`
- 純資産アンカー: `BPS × (1 + ROE)^年数`
- 原文再現: EPS 3,682円 × PER 16.6倍 = 約61,100円
- 原文再現: BPS 34,859円 × 1.106^5 = 約57,600円

後者は、利益を全額内部留保し、ROEが一定で、5年後の株価がその時点のBPSと等しいと置く強い仮定です。配当、自社株買い、増資、利益の変動、資本コストは直接織り込んでいません。二つの値は予測区間ではなく、前提の異なる評価アンカーです。約6万円は一人の論者の入力を再現するシナリオで、金融理論から一意に決まる公正価値でも底値保証でもありません。


### 約6万円への評価正常化とパニック型暴落の分岐

NT倍率は「日経平均 ÷ TOPIX」です。約57,700～61,100円は、榊原先生の入力を使った二つの評価アンカーであり、パニック時の下限ではありません。2026年高値72,831.73円からこの帯までは約16.1～20.8%の下落、7月17日終値64,141.12円からは約4.7～10.1%の追加下落に相当します。

サイトは次の二軸を別々に100点で計算します。

- 評価正常化: NT倍率の反転25、TOPIXの相対優位25、分散型8社のAI連動8社に対する優位30、分散型銘柄への広がり20
- パニック波及: 日経平均の下落速度30、TOPIXと分散型株への波及30、VIXの水準・急上昇20、米国HY OASの水準・拡大20
- 市場経路指数: 「評価正常化スコア - パニックスコア」。+100ほど評価正常化、-100ほどパニック型暴落

VIXはCboe公式定義のS&P 500オプションから計算される30日予想変動率です。米国HY OASは、FRED掲載の投資不適格社債と米国債カーブのオプション調整後スプレッドです。どちらも日本固有の指標ではないため、TOPIXと国内分散型8社への波及を同時に確認します。配点と閾値は公式の売買基準ではなく、直近1・5・20営業日を毎回同じ条件で判定する本サイト独自の早期警戒ルールです。パニック側の30/30/20/20点は、判定対象である日本株の値動きへ60点、米国の変動率・信用確認へ40点を置く役割配分で、過去データから最適化した重みではありません。VIXとOASの各水準は、更新時の取得標本におけるパーセンタイルも画面へ表示します。 VIXは20年の日次終値を使います。FREDのHY OASは提供元注記により2026年4月以降は直近3年だけが公開されるため、OASの順位は3年標本に限られ、5%・6%は現在の公開標本上限を超えます。

画面には、音声解説から抽出した日付に依存しない初心者向け説明を追加しました。VIXは短期の予想変動率、米国HY OASは投資不適格社債と米国債カーブの上乗せ利回り、NT倍率は日経平均とTOPIXの相対差、市場の広がりは売りの波及範囲を表します。OASは新規借入金利や倒産確率そのものではなく、債券の途中償還などに関するオプション性を調整した市場価格ベースの信用スプレッドです。

EN-AI proxyは日本・分散型8社について、品質40、相対割安25、2026年高値からの調整15、日経平均に対する相対回復15を、取得できた項目だけで100点換算します。PERは時価総額÷TTM純利益、PBRは時価総額÷直近株主資本、配当利回りは直近365日の実績配当÷株価という近似です。

## マネーストラテジスト章

Money Strategistの中心動画と関連動画を、長期市場データと照合する章です。動画の説明をそのまま予測として採用せず、次の三種類を画面上で分けます。

- 確認できる事実: 過去の価格、最大下落率、S&P DJI・NY連銀・SECなどの公開資料
- 動画の主張: 過去との類似点、2026年末～2027年春などの危険期間、下落要因の解釈
- 説明用シナリオ: 動画中の18%・30%を2026年7月17日のS&P 500終値へ機械的に当てた青い点線

長期チャートは名目価格指数、配当なし、実数（線形）目盛です。0を基準とし、同じポイント差を同じ縦幅で表示するため、現在の高い指数水準に対して1900年代前半は下部に圧縮されます。赤線は過去の主要10局面で実際に起きた高値から安値までの区間、青線は将来の実績でもチャンネルの正式な指数予測でもありません。2027年6月以降は動画群に一貫した価格目標がないため、2028年末までの価格線を創作せず、危険期間の帯だけを表示します。

系列にも境界があります。1900～1927年はRobert Shiller/Yaleの再構成月次系列、1928年～1957年3月3日は後から整備された歴史・バックテスト系列、1957年3月4日以降が正式なS&P 500です。これらを一本の均質な公式指数として扱いません。

中心動画の主要数値は次のように監査しました。

- 中間選挙年の年内最大下落: 1950～2022年の19回を日次終値で再計算し、平均17.5%、中央値16.6%。動画の約18%は概ね再現
- 上位10社構成比: S&P DJIの2026年7月2日値36.4%で確認
- NY連銀の12か月先景気後退確率: 2026年7月7日更新値は16.0619%。動画の30～49%とは不一致
- SpaceXの売却制限: SEC資料では保有者ごとに366日・決算後の段階解除・180日以内の段階解除などがあり、「2026年12月に一斉解除」ではない
- OpenAIとAnthropic: Anthropicは2026年6月1日、OpenAIは6月8日に機密S-1を提出。公開S-1、上場日、売出株数、ロックアップ対象株数・解除日は未公表なので、2027年春のロックアップは条件付き説明

過去との共通点は、高い評価、少数企業への集中、巨額設備投資、金融引き締めです。ただし、現在の大手AI企業は2000年前後の無収益企業群とは異なり、大きな利益とFCFを持ちます。したがって類似点は暴落日を決める時計ではなく、利益成長が期待へ届かなかった場合の脆弱性を考える材料として使います。

### OpenAI・Anthropic職員株式の流動化

2026年7月19日時点の私募株式取引と、将来の公開市場への供給を分けて表示します。

- OpenAI: Reutersは2025年10月に職員・元職員が約66億ドルを5,000億ドル評価で売却したと報道。評価額比は1.32%。会社の新規調達ではなく、売却代金が売り手へ渡るセカンダリー取引
- Anthropic: Bloombergは2026年2月に約3,500億ドル評価で、投資家側に50～60億ドルの買付余力がある職員売却を報道。これは上限・買い需要であり、全額成立を意味しない
- 累計約140億ドル: The Informationによる両社合計の推計。会社別内訳、取引価格、参加人数を公開資料から独立再現できないため報道値として表示
- 後続評価: OpenAIは2026年3月に8,520億ドル、Anthropicは5月に9,650億ドルのポストマネー評価額を公式発表。私募テンダー後も買い手が存在した事実は確認できるが、評価時点・条件が異なるため公正価値の証明には使わない

会社承認テンダー、機密S-1、IPO、ロックアップ解除を同一視しません。職員売却は分散、納税、生活資金化でも起き、売却そのものは弱気の証明ではありません。一方、ダウンラウンド、売却希望超過、IPOでの大きな既存株主売出、大量ロックアップ解除、上場後の価格低迷、HY OAS・VIX・FCFの同時悪化が重なれば供給ショックとして警戒を上げます。

過去研究では、Brav・Gompersの一般IPO 1,948社でロックアップ満了時の平均異常収益率が-1.2%、Ofek・Richardsonのネット企業では満了前20日から満了後20日までの累積異常収益率が-12%と報告されています。平均値をOpenAI・Anthropicの将来下落率へ直接移しません。

## ITバブル崩壊時の「IT以外への波及」

2000年3月10日のNASDAQ高値から2002年10月9日のNASDAQ安値までを固定窓にし、12系列を同じ条件で比較します。株式分割と配当を調整したYahoo Financeの調整後終値を使い、次の3つを分けます。

- 同じ期間の騰落率: 2000年3月10日から2002年10月9日まで保有した場合の変化
- 期間内最大下落: その窓の中で、各銘柄自身の高値から後の安値まで何%下がったか
- 日本の延長下落: 日本市場は米国の底後も下げたため、2003年4月28日まで最大下落を再確認

期間内最大下落の中央値は、IT・半導体直撃群が約86.1%、市場全体が約54.1%、技術感応型の複合企業が約57.4%、非IT4社が約40.5%でした。個別ではトヨタが約51.1%、ソニーが約73.3%下落しました。ソニーは2000年当時も電子、ゲーム、半導体、情報技術を持っていたため非ITには分類しません。ホンダは期間末では+25.5%でも、途中では最大約37.8%下落しました。

この比較は、非IT企業なら無傷だったという意味ではなく、直撃群より下落が小さい傾向があっても大きな含み損を経験し得ることを示します。ただし、米国景気後退、同時多発テロ、日本のデフレ・銀行不安、イラク情勢が重なった時期であり、IT崩壊だけの因果効果ではありません。存続企業を選んだ小標本なので、生存者バイアスもあります。

## 崩壊スコア

Method v3.9では、崩壊が起きた証拠と、割高への脆弱性を分離しました。

- 崩壊確認80点: 米国価格30、基礎収益・顧客投資25、資本循環・供給15、米国信用10
- 評価への脆弱性20点: 基準FCFシナリオ外の部分と暗黙成長率
- 崩壊確認: 価格、利益、供給・信用の3ゲートがすべて充足し、崩壊確認45/80点以上

SOXの35%下落は2021～22年NASDAQ総合の約36.4%下落を丸めた歴史的アンカーです。200日線下6週は約30営業日の持続を求めるノイズ除去条件です。45/80点は複数群の一致を求める判定ガバナンスです。いずれもSOXの過去局面で最適化した暴落確率の境界ではありません。

評価への脆弱性20点は崩壊確認へ加算しません。DCF残差は余剰現金、保有資産、金融子会社、会計差、循環、一時要因、モデル誤差を含み、バブルの確定額ではありません。

## 業績データの規則

売上、FCF、CapExの変化は、最新四半期と前年同期の同じ四半期を日付で対応させます。TTM系列の隣接値は観測間隔が一定でないため、前年比計算には使いません。

- 比較日が320～410日離れていない場合は未確認
- 売上・FCFは海外AI10社中7社未満しか取れない場合、自動判定に使わない
- CapExは負値の会計表現に依存しないよう投資額の絶対値で比較
- 欠損は0ではなく未確認

## 日経平均の底値モデル

3つの独立した価格アンカーを計算し、最小値から最大値を底値ゾーンとして残します。

- 利益アンカー: `参照日EPS × (1 - 利益悪化率) × ストレス後PER`
- 純資産アンカー: `参照日BPS × ストレス後PBR`
- 歴史アンカー: `直近3年高値 × (1 - 想定下落率)`

EPSとBPSは、日経公式の同じ日の終値と指数ベースPER・PBRから逆算します。2026年7月17日の公式値は終値64,141.12円、指数ウエートベースPER 22.99倍・PBR 2.71倍です。榊原式の市場全体の利益・純資産には、同日の時価総額ベースPER 17.42倍・PBR 1.84倍を別に使います。標準シナリオは利益25%減、PER 16倍、PBR 1.5倍、高値から50%下落ですが、これは予測値ではなく変更可能なストレス前提です。

底値ゾーンへの到達だけでは底打ちとしません。120日安値の更新停止、安値からの反発、50日線、米国HY OAS、日本AI・半導体連動8社の200日線割れを別の確認スコアにしています。8社は本サイト独自の代理指標で、日経225全銘柄の公式市場幅ではありません。

## 企業価値の比較対象

- 海外・AI関連10社: NVIDIA、Broadcom、AMD、Micron、Arm、Marvell、Microsoft、Alphabet、Amazon、Meta
- 日本・AI連動8社: アドバンテスト、東京エレクトロン、ソフトバンクグループ、富士通、キーエンス、日立、信越化学、HOYA
- 日本・分散型8社: ホンダ、キヤノン、トヨタ、ファーストリテイリング、ソニー、任天堂、リクルート、ダイキン

日本株は円、海外株はドルで表示します。金額は直接比べず、評価用FCF利回り、暗黙成長率、時価総額に占めるシナリオ価値を比較します。逆DCFは、現在の株価を正当化するためにFCFが今後10年間で年平均何%成長する必要があるかを逆算するもので、会社予想でも本サイトの成長予測でもありません。

トヨタとホンダは金融サービスを含む連結TTM FCFを直接使わず、公式の非金融事業キャッシュフローをFY2022～FY2026の5年中央値に平準化します。金融事業価値は別加算していません。ソフトバンクグループはNAV/SOTP、複合企業は事業別SOTP、半導体装置会社は循環平準化FCFが本来必要です。
